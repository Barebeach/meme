# 🎥 Automatic Recording System - Complete Guide

## Overview

Your MemeTalk.TV now has a **fully automatic recording system** that:
- ✅ Starts recording when the episode begins
- ✅ Stops recording when the episode ends (after 5 minutes)
- ✅ Saves episode metadata to `episodes.json` database
- ✅ Automatically appears in the **Episodes** page
- ✅ Includes video player for playback
- ✅ NO manual buttons - everything is automatic!

---

## 🎬 How It Works

### 1. Episode Starts
When you start the website from the admin panel:
- 90-second countdown begins
- When countdown reaches 0, episode starts
- **Recording automatically begins** (`🔴 RECORDING STARTED - Episode 1`)

### 2. During the Episode
- All dialogue is recorded with timing and emotions
- Chat messages are saved
- Episode runs for exactly 5 minutes
- Users see: **"⏺️ This episode is being recorded automatically"**

### 3. Episode Ends
After 5 minutes:
- Outro plays automatically
- Recording stops and saves
- Episode metadata is added to `episodes.json`
- **Episode appears in Episodes page immediately!**

## 📁 What Gets Saved

### episodes.json (Database)
Located at: `memetalk-app/episodes.json`

```json
[
  {
    "number": 1,
    "title": "Episode 1: Pepe",
    "guest": "Pepe",
    "host": "Mr Cock",
    "description": "Pepe joins Mr Cock for an unfiltered meme interview",
    "views": 0,
    "date": "Oct 28, 2025",
    "duration": "5:00",
    "videoFile": "episode-1-1730123456789.mp4",
    "thumbnail": "/memetalk.tv.png",
    "recordedAt": "2025-10-28T12:05:00.000Z"
  }
]
```

### Recording JSON Files
Located at: `memetalk-app/recordings/`

Example: `episode-1-1730123456789.json`

Contains:
- All dialogue (Mr Cock & Pepe exchanges)
- All chat messages
- Timestamps
- Emotions used
- Metadata


### To Complete Video Creation

You need to implement FFmpeg video composition in the `createEpisodeVideo` function in `server.js` (lines 800-829).

The video needs to be composed from:
1. **Video clips** from `public/uploads/hosts/` and `public/uploads/guests/`
2. **Audio files** generated by OpenAI TTS
3. **Timing data** from the dialogue recording
4. **Emotion sequences** to switch between video clips

**Example Approach:**
```javascript
// Pseudocode for video composition
for each dialogue in recording:
  - Get speaker (Mr Cock or Pepe)
  - Get emotion (angry, happy, sad, etc.)
  - Get video clip path
  - Get audio file for this line
  - Add to FFmpeg sequence with timing
  
Use FFmpeg to:
  - Concatenate video clips
  - Overlay audio tracks
  - Add transitions
  - Export as MP4
```
